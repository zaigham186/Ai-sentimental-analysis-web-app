THE REAL PROBLEM:
═══════════════════

Your localhost frontend is showing OLD DATA (cached):
  - Shows: 30 participants
  - But database has: 67 participants
  
When you try to delete, you're trying to delete participants that ARE in the 
list display but DON'T EXIST in the actual database anymore (already deleted).

EXAMPLE:
═══════

1. Production has: 67 participants in database
2. You delete 37 participants in production
3. Now database has: 30 participants left
4. Your localhost STILL shows: 67 participants (OLD CACHED DATA!)
5. You try to delete one of the "old 37" participants
6. Backend says: "Not found" (because it was already deleted!)

THIS IS WHY YOU GET THE ERROR.

THE SOLUTION:
═════════════

Clear your localhost cache so it shows FRESH data from database:

METHOD 1: Run the Fix Script (Easiest)
───────────────────────────────────────
Double-click: fix-localhost-cache.bat

This will:
  ✓ Stop all Node processes
  ✓ Clear frontend cache (.next folder)
  ✓ Restart backend
  ✓ Restart frontend
  ✓ Force fresh data

METHOD 2: Manual Steps
──────────────────────
1. Stop backend and frontend (Ctrl+C in terminals)
2. Delete frontend/.next folder
3. Restart backend: cd backend && npm run dev
4. Restart frontend: cd frontend && npm run dev
5. Open http://localhost:3000 in INCOGNITO mode
6. Hard refresh: Ctrl+Shift+F5

METHOD 3: Check Database First
──────────────────────────────
1. Run: cd backend && node check-database-sync.js
2. This shows you REAL participant count in database
3. Compare with what frontend shows
4. If different → cache issue → use METHOD 1 or 2

VERIFICATION:

After clearing cache, your localhost should show:

HOW TO PREVENT THIS:
════════════════════

1. Always test in INCOGNITO mode

3. Restart servers after code changes
   - Backend: Ctrl+C then npm run dev
   - Frontend: Ctrl+C then npm run dev

4. Delete .next folder when in doubt
   - frontend/.next contains build cache
   - Delete it to force complete rebuild
