🔐 Clear Admin Session

Fix "Already logged in as admin" error

📋 What This Does:
This tool will clear your admin session from the browser, allowing you to login fresh. It removes session tokens from localStorage and sessionStorage.
⚠️ Current Problem:
You're seeing "Already logged in as admin" because there's a cached session in your browser. Click the buttons below to clear it.

Current Session Status:

localStorage adminSession: Checking...
sessionStorage adminSession: Checking...
✅ Success!
Admin session has been cleared. You can now login fresh.
📖 Manual Steps (if buttons don't work):
1. Press F12 to open Developer Tools
2. Go to Application tab (or Storage in Firefox)
3. Under Storage section, find:
   • Local Storage → Click your site → Delete adminSession
   • Session Storage → Click your site → Delete adminSession
4. Close Developer Tools
5. Refresh the page
6. Try logging in again
🌐 Localhost URLs:
• Frontend: http://localhost:3000/admin/login
• Backend: http://localhost:5000
