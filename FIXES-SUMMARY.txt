================================================================================
                           IF STILL NOT WORKING
================================================================================

1. FRONTEND NOT LOADING .ENV FILE
   Solution: Restart frontend server
   cd frontend
   # Press Ctrl+C to stop
   npm run dev

2. PORT 5000 STILL IN USE
   Solution: Run kill script
   cd backend
   kill-port-5000.bat
   npm run dev

3. CORS ERROR IN CONSOLE
   Solution: Restart backend
   cd backend
   # Press Ctrl+C to stop
   npm run dev

4. "FAILED TO FETCH" ERROR
   Solution: Backend not running
   cd backend
   npm run dev
